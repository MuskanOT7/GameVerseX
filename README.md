# 🎮 GameVerseX

GameVerseX is a modern multi-game web platform where users can play multiple browser-based games in one place.

## 🚀 Features

- 🎯 Multiple Games (Tic-Tac-Toe, Snake, 2048, etc.)
- 🎮 Game launcher interface
- ✨ Clean and modern UI/UX
- 🖱️ Interactive effects and smooth gameplay
- 📱 Responsive design

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- MYSQL
- PHP
